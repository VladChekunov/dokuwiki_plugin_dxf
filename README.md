# DXF Plugin for DokuWiki
Simple plugin for displaying DXF drawings inside DokuWiki with [dxf-kit](https://github.com/arbaev/dxf-kit) package.

## Installation
1. Copy the plugin to `lib/plugins/dxf/` folder of your DokuWiki
2. Go to Admin > Configure Plugins
3. Enable DXF rendering

## Settings
- Enable DXF rendering — enables/disables rendering
- If disabled, shows raw DXF source code
